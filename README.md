# 月升

追蹤美股，用趨勢、動能、相對強弱與量能自動分析，並依未來約一個月收高的傾向排序。

這是公開報價算出的技術模型，不是投資建議，也不保證下個月上漲。

## 使用

- 大盤顯示標普、納斯達克 100、道瓊、羅素 2000。
- 「下月預測」列出分數最高的標的，附一個月基準與區間。
- 點進個股可看走勢、均線、RSI、相對標普與量能。
- 搜尋代碼可加入名單；星號會把追蹤存在這台裝置。
- 「請 Grok 寫研究筆記」會依畫面上的數字再寫一版。需要伺服器環境變數 `XAI_API_KEY`。

## 本地執行

```bash
npm install
npm run dev
```
